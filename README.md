# Fluidkey drain tracker

Independent on-chain tracker of the 19 November 2026 theft from Fluidkey accounts: totals by chain, attacker addresses, money flow and timeline.

- Live page: see the repository's GitHub Pages link.
- `data/*.json` holds the datasets behind the page and is refreshed every few minutes while the tracker is running.
- Addresses marked "suspected" match the theft pattern but are not confirmed. Not affiliated with Fluidkey.
